This repository contains my solutions to the exercises, homeworks and final exam project for the course *Practical Programming and Numerical Methods* (spring 2026).

## Structure and execution

Each assignment is isolated in its own dedicated directory with a flat folder structure.

Every assignment folder contains both the source files and all the output files for the assignment. So everything is built.

The Makefile in each assignment folder is constructed such that running `make` will generate *all* output files for the assignment, while running `make clean` will remove *all* output files.

For code generation and debugging assistance, the AI models *GPT-5.5 Instant* and *Gemini 3.5 Flash* has been used.
