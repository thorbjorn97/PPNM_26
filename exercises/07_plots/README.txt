# "README.txt" file: For instructions on usage

# Instructions (for Makefile and plot_script.sh usage in terminal):
`make` 			<-- to build the program (creates main executable and object files).
`make out`   	<-- to execute the program and save output to Out.txt.
`make plot`		<-- to execute the plotting script plot_script.sh (generates .dat files and .png plots).
`make clean` 	<-- to remove all generated files

# end
